# TechRen Academy

Premium interactive website for TechRen Academy — a programming and English education center.

## Stack

- React
- Vite
- Anime.js
- CSS (no Tailwind)

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

Dark mode is the default. Theme preference is stored in `localStorage` as `techren-theme`.
